# Sprint 1 - GitHub Clone

## Objective
The goal of Sprint 1 is to build the basic working version of a Git-based code hosting platform where a user can store and view their code online.

In this sprint, we will implement user authentication so that a user can sign up using email and password and log in securely. Once logged in, the user should be able to create and manage repositories with basic configuration such as public or private visibility.

The system should integrate core Git functionality. When a repository is created, it should be initialized properly so that the user can connect it with their local system and perform standard Git operations like push and clone using :contentReference[oaicite:0]{index=0}.

The focus is to ensure that repositories are correctly created, stored, and accessible through the backend. The UI should allow users to view their repositories and basic details, forming the foundation for future features like file browsing and commit history.

This sprint is focused on building a strong base, not on advanced features. By the end of this sprint, a user should be able to sign up, log in, create a repository, and connect it with their local Git setup.
